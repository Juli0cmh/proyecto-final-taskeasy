# TaskEasy - Sistema de Gestión de Tareas y Proyectos

## Descripción del Proyecto
TaskEasy es una aplicación web full-stack diseñada para la gestión eficiente de tareas y asignaciones de proyectos. Permite a los usuarios organizar sus actividades diarias, gestionar catálogos y controlar roles y permisos de forma segura mediante una arquitectura desacoplada (SPA con React en el frontend y una API RESTful con Laravel en el backend).

## Tecnologías Utilizadas
* **Backend:** PHP 8.x, Laravel, Laravel Sanctum (Autenticación API), Eloquent ORM.
* **Frontend:** React, Vite, React Router, Tailwind CSS / CSS Modules, Axios / Fetch API.
* **Base de Datos:** MySQL.
* **Control de Versiones:** Git y GitHub.

---

## Requisitos Previos
Antes de iniciar el proyecto, asegúrate de tener instalado en tu equipo:
* PHP (versión 8.2 o superior) y Composer.
* Node.js y npm.
* Servidor de base de datos MySQL (puedes usar el entorno integrado de Laragon o XAMPP).
